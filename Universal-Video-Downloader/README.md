# 通用视频下载器

这是一个运行在 Scripting 中的 yt-dlp 通用媒体下载器。首页可在“常用模式”和“高级模式”之间完整切换，并会持久记录上次使用的模式。常用模式读取剪贴板后直接解析第一个链接；高级模式的“从剪贴板获取”只把文本填入多行编辑框，由用户确认设置后再开始批量下载。两个入口使用不同标题与图标明确区分行为。下载器使用 Scripting 内置 FFmpeg、AVAsset 与 MediaComposer 处理媒体。

## 使用方法

### 常用模式

1. 在视频网站复制链接或包含链接的分享文案；
2. 运行“通用视频下载器”；
3. 点击“读取剪贴板并继续”，程序会提取第一个链接并直接解析；
4. 在确认页选择高清合并或兼容下载；
5. 下载时页面会显示阶段、百分比、已下载大小、速度与 ETA；
6. 文件保存到 Scripting Documents 下的 `Video Downloads`，完成后发送本地通知。

### 高级模式

1. 在常用模式首页底部点击“切换到高级模式”；
2. 在多行输入框中输入一个或多个链接，也可以点击“从剪贴板获取”填入包含多个链接的文本；
3. 调整格式、字幕、缩略图、播放列表和时间范围；
4. 点击“开始高级下载”，链接会按输入顺序逐个执行并汇总结果；
5. 页面最下面可以“切换回常用模式”。

首页模式会持久保存，下次运行时自动打开上次使用的模式。高级模式输入内容在本次运行内切换模式时不会清空。

## 首次初始化

首次运行会检查共享 Python 环境中的 `yt-dlp`。如果未安装，页面会要求用户主动安装：

```sh
python -m pip install --disable-pip-version-check --no-input --no-deps --upgrade yt-dlp
```

使用 `--no-deps` 是为了避免在 iOS 沙盒中编译包含原生扩展的可选依赖。yt-dlp 核心 wheel 本身是跨平台的 `py3-none-any` 包。

## 快捷下载

### 高清音视频合并

- yt-dlp 选择设备兼容范围内较高画质的 MP4 视频流和 AAC 音频流；
- 优先 H.264，没有 H.264 时尝试 HEVC，最高 2160p、60fps；
- TypeScript 层调用 Scripting 内置 FFmpeg，以 `-c copy` 无损封装进 MP4；
- FFmpeg 失败或输出验证不通过时，回退 `MediaComposer.composeAndExport` 重新编码；
- AVAsset 验证输入时长、轨道和最终文件可播放性；
- 成功或失败都会清理临时独立流和进度文件。

### 兼容模式

- 直接下载已经包含声音和画面的单文件；
- 优先 H.264/AAC MP4，其次其他 MP4 或单文件格式；
- 不需要合并，速度更快、临时空间更少，但画质可能低于高清独立流。

## 实时进度与完成通知

快捷模式和高级模式均使用 yt-dlp `progress_hooks` 将小型 JSON 快照原子写入任务目录，TypeScript 在下载运行期间轮询该文件，因此可以显示：

- 当前阶段；
- 下载百分比；
- 已下载大小与总大小；
- 实时速度；
- ETA；
- 播放列表当前项目。

网站未提供总大小时会显示不确定进度。FFmpeg、MediaComposer、验证和发布阶段没有可靠的逐帧回调，因此只显示阶段型不确定进度，不伪造百分比。

下载成功或部分成功后会立即安排本地通知。通知权限被拒绝或发送失败不会影响已经下载的文件。脚本支持 Scripting 最小化，但这不等同于系统保证永久后台执行；请勿强制结束 Scripting。

## 高级模式

高级模式是首页的一种完整形态，不再从确认页弹出 Sheet。它在页面顶部提供多行链接输入，在中部提供完整下载设置，在最底部提供“切换回常用模式”。

- 每行可输入一个链接，也可以粘贴包含多个链接的分享文案；
- 自动提取 HTTP(S) 链接并去除重复项；
- 多个链接按输入顺序逐个处理，单个失败不会阻止后续链接；
- 所有链接共用本次选择的高级设置；
- 每个链接本身仍可使用播放列表范围；
- 最终统一汇总产物、完成项目和失败记录。

高级视频只把兼容的 MP4/MOV/M4V 主视频尝试保存到照片 App，音频、字幕、缩略图和其他容器只保留在 Files。

### 视频

- 画质：最佳、2160p、1440p、1080p、720p、480p、360p；
- 容器：跟随源格式、MP4、WebM、MKV；
- 编码：自动、H.264、HEVC、AV1、VP9；
- 独立音视频流由 TypeScript 调用内置 FFmpeg 无损合并；
- MP4、WebM 会筛选可无损封装的流组合，MKV 接受范围更宽；
- 如果目标组合不能无损封装，会保留已下载的原始流并在结果页报告部分失败。

### 仅音频

- 跟随源格式；
- M4A，支持 128/192/256/320 kbps；
- MP3 选项已提供，但当前 Scripting 内置 FFmpeg 构建没有 MP3 编码器；选择后会保留原始音频并显示转换失败，等待运行环境增加编码器或后续提供替代方案。

提高目标码率不会改善源音频本身的音质。

### 字幕与缩略图

- 人工字幕、自动字幕可独立启用；
- 支持一个或多个语言代码，留空表示全部可用语言；
- 目标格式：最佳可用、VTT、SRT、TTML；
- 转换失败时保留网站提供的原始字幕格式；
- 可下载网站提供的缩略图；
- 字幕和缩略图作为独立文件发布，不进行语音转录，也不使用 AI 生成字幕。

### 播放列表

- 支持指定起始项和结束项；
- 每次最多处理 50 项，避免误下载超大频道；
- 每项独立下载并收集产物；
- 无法获得独立 HTTP(S) 地址的条目会跳过并报告失败，不会错误重复下载第一项；
- 成功文件和失败记录会同时显示在结果页。

### 自定义时间

- 支持秒、`MM:SS`、`HH:MM:SS`；
- 可以只设置开始或结束，也可以同时设置；
- 当前使用 FFmpeg `-c copy` 快速裁剪，不重新编码；
- 切点可能落在相邻关键帧，不保证帧级精确；
- 与播放列表同时使用时，同一时间范围会应用到每个条目。

## Cookie 登录

部分网站需要登录才能访问视频内容。脚本提供三种 Cookie 获取方式，Cookie 以 AES-256-GCM 加密后存储在设备本地 Keychain 中（不同步 iCloud），仅在下载时解密为临时文件供 yt-dlp 使用，下载完成后立即清理。

### 隔离 WebView 登录

- 打开一个隔离的 WebView 页面，用户在其中登录目标网站；
- 登录完成后脚本自动提取 Cookie 并转换为 Netscape 格式；
- 隔离模式不会持久化 WebView Cookie，每次登录都是全新会话；
- 适合需要临时登录但不希望在设备上保留登录状态的场景。

### 持久 WebView 登录

- 使用共享的 WKWebView Cookie 存储，登录状态在脚本运行间保持；
- 适合需要长期登录状态的场景，但会在设备上保留 Cookie；
- 脚本会在使用前提醒用户持久模式的安全风险。

### cookies.txt 导入

- 支持导入 Netscape 格式的 cookies.txt 文件内容；
- 实时校验格式，显示有效 Cookie 数量和域名；
- 适合已有浏览器导出 Cookie 的用户。

### Cookie 管理

- 在首页点击“管理 Cookie”查看已保存的 Cookie 配置；
- 可以删除单个 Cookie 配置或全部清除；
- Cookie 的明文查看受 LocalAuth 生物识别保护。

## 结果与文件策略

高级任务使用 `Video Downloads/.advanced-download-jobs` 隔离临时文件，发布完成后清理任务目录。结果页支持：

- 请求项目数、完成项目数、产物数和失败数；
- 查看首个或全部文件路径；
- 分享全部产物；
- 保留部分成功的媒体、字幕和缩略图；
- 零产物任务进入失败页，不发送误导性的完成通知。

快捷高清任务继续使用 `.native-merge-jobs`，并清理超过 24 小时的遗留任务。

## 当前能力边界

“通用”表示支持当前 yt-dlp 能解析的多种视频网站，不代表所有网站都能下载：

- Cookie 登录已实现（隔离 WebView、持久 WebView、cookies.txt 导入），Cookie 以 AES-256-GCM 加密存储在设备本地 Keychain 中；
- DRM 内容无法下载；
- 某些站点需要额外 JavaScript challenge runtime；
- 签名字幕或缩略图 URL 可能在长任务中失效；
- 高级模式的编码选项用于选择网站已有流，不进行任意视频编码转换；
- `Python.run` 当前没有可靠的强制取消和有效超时；
- FFmpeg 与 MediaComposer 阶段没有可靠的实时百分比或统一取消句柄；
- MP3 因内置 FFmpeg 缺少编码器暂时不能生成；
- 播放列表、竖屏、HDR、多语言音轨和特殊站点仍需要更多实站验证。

遇到网站规则变化时，可在主页面执行“检查更新并重新安装”。

## 项目文件

- `index.tsx`：常用/高级双模式首页、模式偏好持久化、常用模式剪贴板直达、高级批量输入、批量链接队列、页面状态机、实时进度、结果、通知与分享；
- `downloader.ts`：快捷下载、独立流选择、实时进度、内置 FFmpeg 合并与 MediaComposer 回退、文件令牌取消机制；
- `advanced_downloader.ts`：高级选项、播放列表、多产物、字幕、缩略图、音频转换和时间裁剪、文件令牌取消机制；
- `cookie_vault.ts`：Cookie 的 AES-256-GCM 加密存储、Keychain 密钥管理、cookies.txt 格式校验与转换、临时 Cookie 文件管理；
- `cookie_ui.tsx`：Cookie 管理 UI，包括隔离 WebView 登录、持久 WebView 登录、cookies.txt 导入、Cookie 列表与删除；
- `yt_dlp_installer.ts`：yt-dlp 检测、安装和更新；
- `script.json`：脚本元数据和版本。
